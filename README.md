# WirelessPower 重制版 (WirelessPower_Remake)

原作：feyko（https://ficsit.app/mod/7Qy2jZQQKtuFmW ，源码 https://github.com/Feyko/satisfactorymods ）。
本仓库为社区重制版，作者 **Monsue**。

## 功能
- 无线电力传输（无需电缆即可向范围内用电设备供电）
- v1.1.5 修复：同进程换档（读档 / 切换会话）崩溃问题

## 环境
- 基于 SML 3.x 与 SMLStarterProject
- 依赖：`SML ^3.12.0`
- 支持 Steam / EGS / 专用服务器

## 构建
在 SMLStarterProject 工程内以 Shipping 配置 PackagePlugin 本 mod 即可。
